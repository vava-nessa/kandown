# Relooker le board façon Linear

## Context

Le background actuel des tâches est jugé "moche" : colonnes saturées (fuchsia, cyan, amber, pink), carte vs fond manque de hiérarchie, noise-overlay ajoute du grain inutile. Cible : look Linear (clean, épuré, dark/light auto selon le système, colonnes neutres).

## Subtasks

- [x] Nettoyer `globals.css` : retirer la noise-overlay, affiner la board-bg (pointillés) et ajouter une variante light
- [x] Refondre les tokens du skin "kandown" (dark + light) pour un look Linear : fond quasi noir / blanc cassé, cartes à élévation subtile, bordures très discrètes
- [x] Raffiner les autres skins (Graphite, Sage, Cobalt, Rose) pour rester cohérents
- [x] Repenser la carte : élévation subtile, bord fin, hover plus doux, ombre légère
- [x] Repenser la colonne : header plus aéré, fond neutre par défaut, accents sur le focus seulement
- [x] Retirer la noise-overlay de `Board.tsx` et `EmptyState.tsx`
- [x] Mettre à jour `kandown.json` : `theme: "auto"`, reset des `columnColors` à neutre
- [x] Vérifier visuellement (screenshots) en dark + light
- [x] Lancer le typecheck/build pour s'assurer qu'on n'a rien cassé
- [x] Commit

## Notes

- Linear dark : fond quasi noir pur, cartes gris très sombre, bordures très discrètes, pas de couleur de colonne
- Linear light : fond blanc cassé, cartes blanches, bordures gris clair
- Garder le système de skins pour les utilisateurs qui aiment les couleurs (Sage, Cobalt, etc.) — seul le kandown devient Linear
