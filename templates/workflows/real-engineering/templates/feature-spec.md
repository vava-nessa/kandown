Describe the product outcome this specification should enable.

## Context

Explain the problem, affected users, current behavior, and supporting research.

## Constraints

- Product or repository constraint
- Compatibility or performance constraint
- Delivery constraint

## Problem statement

Describe the observed problem without prescribing an implementation.

## User outcomes

- As a [user], I want [behavior], so that [value].

## Work checklist

- [ ] Validate the problem and user outcomes.
- [ ] Resolve material open questions.

- [ ] Approve the specification.
- [ ] Create tracer-bullet slices and dependencies.

## Verification

Explain how each acceptance criterion can be demonstrated without relying on implementation details.

## Evidence

Link user decisions, research, prototypes, or observed current behavior.

## Completion report

Record approval, final scope, selected slices, and any changed decisions.
