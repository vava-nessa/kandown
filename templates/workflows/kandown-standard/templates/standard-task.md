# Standard task

## Goal

State one observable outcome.

## Context

Link the request, relevant files, prior decisions, and current behavior.

## Constraints

- Repository or platform constraint
- Behavior that must not change
- Explicitly excluded scope

## Acceptance criteria

- [ ] The intended behavior is observable.
- [ ] Relevant existing behavior remains intact.
- [ ] Required repository checks pass.

## Work checklist

- [ ] Read repository guidance and affected code.
- [ ] Confirm the smallest coherent implementation.
- [ ] Implement the change.
- [ ] Run focused verification.
- [ ] Run required broader checks and inspect the diff.

## Verification

List exact automated checks and the direct runtime or manual scenario when relevant.

## Evidence

- Command and concise result
- Runtime observation or artifact
- Diff range reviewed

## Completion report

Summarize the delivered behavior, important decisions, files changed, and verification result.

## Follow-ups

Record only deferred work that is outside this task. State why it was deferred.
