# 0.56.0 - 2026-09-05 - "Beautiful UI"

## Added

- Multi-category filter in the web header: the dropdown next to the task count
  now accepts several categories at once. Each selection shows as a chip with a
  small X so it can be removed in a click, the board and list views show the
  tasks of any selected category, and the grouped stacks render already
  expanded and locked while a filter is active. Clearing the filter restores
  the normal board.
- Agent model picker in the chat, with steer and queued delivery so messages
  reach the right model at the right moment, and a write conflict guard that
  protects in-progress edits from being overwritten.
- One-click choice cards: agent questions that carry options render as
  selectable cards with a let-me-type escape hatch and an answered state, and
  PROPOSE lines render recommendation cards with Accept and Dismiss actions.
- Kandown agent charter injected into every chat session whatever the harness,
  so the agent knows it manages task markdown rather than code and learns the
  [[t123]], [show:], @mentions, options and PROPOSE affordances.
- BeautifulUI design system (MIT, beautifului.dev) scoped under .bui so the
  Kandown theme stays untouched: colors, layered shadows, radii, easings and
  keyframes, plus four ported components covering pixel-grid loaders, reasoning
  traces, streaming text and approval cards, all browsable in a hidden gallery
  at #bui.
- Chat activity upgrades: a pixel-grid loading state with elapsed seconds, a
  reasoning-trace activity block, streaming suggestion chips, context cards
  above mentioned user messages, line-numbered code blocks, and a rebuilt
  composer in the catalog style.

## Changed

- 21 new parser and fold tests cover the choice-card and PROPOSE rendering.
- All 47 locales gained the new agent UI strings, about 1,400 additions with
  placeholders intact.
