# 0.39.5 — 2026-07-26 — "One Link"

## Changed

- **The GitHub star count in the website header is now a single link.** The header carried two separate links to the same repository sitting next to each other — the GitHub mark, then a bordered pill holding the star count. They are now one: the mark, the word "GitHub", a star, and the number, reading left to right as one phrase. Hovering highlights the whole group, tabbing through the header stops on it once instead of twice, and a screen reader announces the repository once rather than repeating it.
- **The box around the star count is gone.** Its outline separated the count from the mark beside it and made two controls out of one. Every other item in the header — search, npm, the menu button — is unboxed, so the count now matches them.
- **The star is GitHub's own icon.** It was previously a redrawn star, slightly heavier than the real one and gold rather than inheriting the link's colour. It now uses the same shape and the same colour GitHub does, so the whole link lights up as one unit.
