# 0.39.8 — 2026-07-26 — "Under The Mark"

## Changed

- **The header's star and download counts moved below their logos.** Each count now hangs under the mark it belongs to, in very small grey type, instead of sitting beside it. Read left to right, four elements in a row made each link compete with the navigation; stacked, the logo is what you see and the number is a footnote available if you want it.
- **The logos stay exactly where they were.** The counts are positioned rather than stacked in the layout, so each link stays the height of its own mark and keeps sitting on the same centre line as the search field and the App button. Laid out as two rows, both logos would have drifted upward by half a line and quietly stopped aligning with everything else in the bar.
- **All colour is gone from the counts.** No fill behind them and no brand tint on them — both were tried and both made the quietest corner of the header the loudest. A filled chip drew a box around the least urgent element on screen, and colouring each count to its service made the numbers read before the marks above them, which is backwards.
- **The npm link now names itself in words**, like the GitHub link beside it. At this size the wordmark works as a shape rather than as text, and without a label the two links were not built the same way.
