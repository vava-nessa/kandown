# 0.59.0 — 2026-09-09 — "Agent Page"

## Added

- The agent chat is now a full-page view: Agent opens a harness-style page with a centered conversation column and its own header (conversation title, harness logo, live-turn marker, usage, autopilot, panel toggles, new conversation). Mobile keeps the fullscreen chat overlay.
- The left rail lists every conversation: always visible, live indicator while an agent turn runs, filter input, date grouping (Today / Yesterday / Last 7 days / Older), full tooltips, forget and new-chat actions. It replaces the in-chat dropdown switcher.
- A per-conversation right panel next to the chat: an editable Task tab (the open task, subtasks included) and a Changes tab (touched files plus live before/after diffs). User-resizable through a drag handle (320 to 560px, persisted), keyboard resize and double-click reset.
- A bb-style model picker: search field, provider logo tabs with model counts, the full per-harness catalog (no more 16-entry cap), Current and New badges, a custom-model entry, and picks persisted per harness.
- Per-conversation composer drafts that survive conversation switches and page reloads, plus a centered welcome screen ("What can I do for you today?") with a larger composer for empty conversations.
- Command palette additions: "Go to board", "Go to list", "Go to archives", "Open agent page", and a Conversations quick switcher that resumes the most recent sessions.
- The agent view can collapse the rail to a 56px icon-only mini rail instead of hiding navigation.
- The daemon stores a preview of each conversation's opening prompt in the session index, so a conversation can always hand its first message back to the composer.

## Fixed

- The model picker never worked in the browser: /api/agent/models was fetched without the daemon token and always answered 401. It now goes through the authenticated helper, and the picker lists every model the harness reports.
- Clicking Board, List or Archives (rail, command palette, cmd+1/2) shows the requested view even when a task editor is open: the editor closes with unsaved edits stashed instead of keeping priority.
- Conversations whose harness crashed before registering no longer dead-end on "no harness session to resume yet": they open with the original prompt restored in the composer, and sending starts a fresh session on the same harness and task.
- Harness names in the rail and the page header render as brand logos instead of uppercase text chips that clipped in the narrow rail.
- The model catalog request also stopped leaking a per-keystroke fetch while the chat surface was idle, and removed a vestigial /api/migrate-tasks request that 404'd on every page load.

## Changed

- The SessionSwitcher dropdown is removed: the rail conversation list is the single switcher, and the chat header keeps the session title and actions.
- The session event stream reconnects while the agent page is open, so live indicators stay accurate for the conversation on screen.
