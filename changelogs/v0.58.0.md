# 0.58.0 - 2026-09-08 - "Clean Slate"

The whole web UI was redesigned around one rule: one boundary per surface.
The theme supermarket is gone in favor of a single polished base theme, a
left navigation rail takes the views out of an overloaded header, and the
board reads calm: neutral columns, one hairline per card, quiet category
tints.

## Added

- **Left navigation rail.** Board, List, Archives (with a count badge) and
  the Agent chat live in a 56px icon rail that expands to a full sidebar on
  click, collapsed by default and remembered across sessions. Settings, the
  light/dark mode switch and a git footer sit at the bottom; the footer
  shows the active branch plus a "wt" badge when the project is a linked
  git worktree, and clicking it copies the branch name. A compact button
  cycles auto/light/dark while the rail is collapsed. Backed by a new
  read-only `GET /api/git` endpoint (also mirrored in the Vite dev server);
  the footer hides itself whenever git info is unavailable.
- **Optional column color accents.** Columns are neutral containers now;
  the configured column color can come back as a small dot next to each
  column title through the new `ui.columnAccents` setting (off by default).
- **Header overflow menu.** Command palette, reload, the show/hide metadata
  master switch, density and the keyboard cheatsheet collapsed behind one
  dots button, replacing six icon-only buttons in the top bar. The floating
  bottom-right metadata button is gone with it.
- New interface strings (`nav.*`, column accents, overflow menu) shipped in
  all 48 locales.

## Changed

- **One clean base theme.** The four bundled presets (shadcn, vercel,
  linear, kandown) are replaced by a single `base` theme: neutral paper
  surfaces, the brand lime reserved for primary actions and focus, glass
  off, 6px radius, Inter everywhere. Every previously valid skin id
  resolves to `base`, so existing configs need no migration. The theme
  engine, its inheritance field and the `kandown theme install` CLI flow
  stay: future variants inherit from `base`, and installed community
  themes still resolve through `ui.skin`.
- **A calm board.** Columns lost their pastel fills and borders; cards
  carry exactly one hairline with a hover-only shadow; the tinted,
  double-bordered envelopes around category groups are replaced by one 3px
  category-colored line that starts at the group title and runs along its
  children; category chips are quiet 13%-alpha tints with mode-aware label
  colors instead of saturated pastels.
- **Calmer cards.** The subtask progress bar thickened from 3px to 6px, the
  task id moved into a small dedicated box in the card's top-right corner,
  the assignee name renders smaller and bold (and still only when someone
  is actually assigned), and the hover actions shifted so nothing overlaps.
- **Frameless task editor.** The ALL TASKS panel is a flat index without
  boxes or shadows, the editing sheet is the single paper surface, and the
  task id renders as plain text. Remaining lines are functional: sheet
  dividers, list hairlines, the dashed add-category affordance.
- **Slimmed settings.** The Appearance section now offers language, mode,
  category chips and column accents; the skin/font/background pickers and
  the Themes section are gone, and the TUI settings dropped the inert
  skin and font rows.

## Removed

- The theme customizer UI: modal, floating launcher, preview cards, theme
  gallery panel and the font/background pickers. Core behavior is kept:
  themes installed via the CLI still resolve, and `GET /api/themes` still
  serves the registry.
