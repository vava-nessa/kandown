# Card layout — # left of title, separator-only, full title, grow with long titles

## Context

User reported the board rows were using a card-with-border + gap layout
that produced a "crado double bordure" effect between rows, that the
title was being truncated (`line-clamp-1` in compact, `line-clamp-2` in
comfortable), and that the task number was on its own row above the
title instead of inline with it.

The user also wanted compact and comfortable densities to **both** grow
freely with long titles (different padding, same growth), and asked
for the list view to follow the same rules.

## Fix

Replaced the bordered-card pattern with a single-hairline separator
between rows, moved the `#` inline with the title, removed the
`line-clamp` on the title, and made the row height grow with the
title text in both densities. Same change applied to `ListRow` so the
list view also shows full titles and grows with them.
