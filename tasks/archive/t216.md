# Add global daemon refresh command

## Context

Vava found that global npm updates can leave already-running per-project Kandown daemons on older versions. She wants a global refresh that reboots all open Kandown daemons with the updated CLI version.

- [x] Keep auto-update daemon refresh behavior compatible
  report: Kept the old auto-update wrapper so successful package updates still refresh open projects and restart only outdated daemons.
