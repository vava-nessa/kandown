Ajouter un bouton dans la colonne "Done" qui propose soit de archiver toutes les tâches, soit de les supprimer toutes.

## Subtasks

- [x] Ajouter le menu d'actions groupées dans la colonne terminale
- [x] Persister l'archivage et la suppression en mode navigateur et serveur
- [x] Tester les confirmations, les erreurs partielles et le reload du board

## Changes
- Added **Manage tasks** menu to the configured terminal column in both Board and List views, exposing **Archive all** and **Delete all** entries with explicit confirmations that name the terminal column and exact count.
- New `bulkArchiveTasks` and `bulkDeleteTasks` store actions use `Promise.allSettled` over strict task reads so one failed file does not abort the batch. An in-flight guard prevents two destructive runs from racing.
- `nextTaskId` now considers archived ids so newly created tasks never reuse a number that already lives in `tasks/archive/`.
- Server mode archive round-trip is now functional: `/api/tasks/:id/archive` and `…/unarchive` routes accept the full serialized task body, with task-id validation. `vite.config.ts` dev middleware mirrors the same routes at the canonical project-root `tasks/` location. File watcher now tracks `tasks/archive/*.md` too.

## Decisions
- Used the configured terminal column (`terminalStatus(config)`) instead of a hard-coded `Done` so renames stay compatible.
- The bulk menu uses `column.tasks` (not the filtered set) so hidden tasks are not silently skipped.
- Deletion is permanent and explicit (`Permanently delete all N tasks in "<column>"? This cannot be undone.`) to match the existing card delete flow.
