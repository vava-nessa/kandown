Just like the delete button that appears when hovering a task in the column or list view, there should be a small archive icon right next to the delete button for quick archiving.

## Subtasks

- [x] Add the archive icon to cards in the board and list views
- [x] Verify the move to the archive and the visual feedback
- [x] Test accessibility and the hover/loading states

## Changes
- Cards in Board and List views (including the `CardStack` rows on expansion) now expose an `Archive task` icon immediately to the left of the existing guarded delete icon. Both icons reveal on hover or keyboard focus (`group-hover`/`group-focus-within`).
- The archive action is a single click (no second confirmation) because archiving is reversible from the archive view. The delete button keeps its existing two-click confirm-then-fire pattern.
- New `isArchiving` flag disables the archive button while the store action is pending and prevents reentrancy between archive and delete clicks. A mounted-ref reset keeps the buttons interactive under React StrictMode.
- Archive success moves the file to `tasks/archive/`, the card disappears from the active board, and the header archive counter increments; the archive view shows a one-click Restore action.

## Decisions
- Reused the existing `archiveTask` store action (which also closes an open drawer and reloads the board) instead of adding a parallel codepath. This keeps the drag/click guard logic on the card minimal and the watcher's SSE broadcast consistent.
- Paired archive + delete in a single absolutely-positioned flex group so the hover area stays small but the keyboard focus target is shared (focusing the card surfaces both controls).
