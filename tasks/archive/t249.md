# Add the Kandown brand theme and make it the real default

## Context

`DEFAULT_CONFIG.ui.skin` already said `'kandown'`, but `LEGACY_SKIN_MAP` mapped
`kandown` to `vercel`, so every fresh project opened in monochrome Vercel colors
instead of the brand's. Kandown shipped without its own theme.

The palette is the one registered for the website: `#88E138` brand lime,
`#7AD12A` its light-background variant, `#0CE931` the hero shader green,
`#F1FFB8` pale lime, `#EBEBEB` neutral border grey.

## Subtasks

- [x] Build the `kandown` preset from the brand palette, light and dark
  report: Mapped the palette to the FABLE_UI token set in both modes, with 4px radius, soft shadows, glass on, and comfortable density to match the website's 4px-radius pass.
- [x] Make it the actual default instead of an alias for Vercel
  report: Dropped the `kandown -> vercel` entry from LEGACY_SKIN_MAP, moved the preset to index 0 of THEME_PRESETS, and pointed the normalizeSkinId fallback at 'kandown'.
- [x] Mirror the preset into the split `src/lib/themes/` directory
  report: Added `src/lib/themes/kandown.ts` and registered it first in the themes index so both copies of THEME_PRESETS stay consistent.
- [x] Audit contrast and verify the build
  report: WCAG audit of every foreground/background pair passes AA in both modes except `text-primary` on light (2.05:1, inherent to the brand lime, left as-is and flagged); `success` was darkened to reach 4.57:1. Typecheck and `pnpm build` pass.
