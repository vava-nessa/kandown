# [website] CometCard hero wrapper

## Context

The hero product lockup (kandown logo + brand morph + install command) currently
lives in a flat dark wrapper (`rounded-3xl border border-white/15 bg-black/85`).
It's static. vava wants to swap that wrapper for a CometCard: a 3D-tilted
interactive card with a glare highlight that follows the mouse, and a hover
state that scales the card forward.

This is a copy-paste integration from a shadcn-style prompt: the CometCard
component uses `motion/react` + `useMotionValue/useSpring/useTransform` for the
3D tilt, plus a `mix-blend-overlay` glare layer.

The website already pulls `framer-motion@12.42.2` (rebranded to `motion`), so we
rewrite the imports to `framer-motion` to avoid installing a second package for
the same library. No `cn` helper conflict — `~/lib/utils` already exposes it.
