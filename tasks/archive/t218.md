# Implement FABLE_UI customizable theme system

## Context
Transition from 5 hardcoded HSL skins to an open, JSON-driven theme engine (`KandownTheme`) with appearance tokens, 8 curated presets, live mini-board preview gallery, theme customizer UI with contrast checking, and design refinements.

## Subtasks
- [x] Step 1: Extend types and appearance tokens in `src/lib/types.ts`
  report: Added `KandownTheme`, `ThemeTokens`, `ThemeAppearance`, `ThemeFonts` interfaces, updated `SkinId` to string, and added `customThemes?: KandownTheme[]` to `KandownConfig.ui`.
- [x] Step 2: Refactor theme engine in `src/lib/theme.ts` with 8 curated presets and JSON inheritance
  report: Created `THEME_PRESETS` with 8 themes (Vercel, Linear, Claude, Apple, Stripe, Paper, Catppuccin, Terminal), added custom theme registration (`registerCustomThemes`), inheritance resolving (`resolveTheme`), legacy skin mapping, and set appearance variables (`--radius`, `--shadow-*`, `--font-display`, `--motion-scale`, `--card-blur`).
- [x] Step 3: Configure CSS tokens in `src/styles/globals.css` and `tailwind.config.js`
  report: Defined `--radius`, `--font-display`, `--shadow-*`, `--motion-scale`, `--card-blur` variables in `:root`, updated body font-size to 15px, added unified `:focus-visible` ring styles and smooth mode transitions, and mapped Tailwind `borderRadius` & `fontFamily.display`.
- [x] Step 4: Create `ThemePreviewCard` component for live mini-board previews
  report: Created `src/components/ThemePreviewCard.tsx` rendering isolated live mini-board previews (3 columns, mini cards, active state, duplicate/edit/export actions) using theme HSL tokens and appearance CSS variables.
- [x] Step 5: Create `ThemeCustomizerModal` component for creating/editing custom themes with contrast check & JSON export
  report: Created `src/components/ThemeCustomizerModal.tsx` providing visual theme editing for HSL tokens, radius sliders, shadow levels, density, glass, motion, live WCAG 2.1 contrast ratio calculator, and JSON import/export editor.
- [x] Step 6: Update `SettingsPage.tsx` with theme gallery, custom theme actions, and store integration
  report: Built `ThemeGalleryPicker` in `SettingsPage.tsx` with live previews of 8 presets + custom themes, theme creation button, duplicate/edit/export actions, and visual customizer modal integration.
- [x] Step 7: Update `store.ts` and config loading for `ui.customThemes`
  report: Connected custom themes registration in `applyConfigTheme` (`registerCustomThemes(config.ui.customThemes)`) to persist and apply user JSON themes from `kandown.json`.
- [x] Step 8: Apply design refinements (typography, scrollbars, focus rings, transitions) and verify build
  report: Verified full build (`pnpm build`) passing cleanly with zero errors across TypeScript, Vite, and Tsup.
