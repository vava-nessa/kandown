  ## Changes
  - Added an `inline` prop on `ListRow` so the same renderer serves both the
    wide ListView/ArchiveView and the narrow TaskWorkspace sidebar.
  - In inline mode the title row is `items-center` with `truncate` instead of
    `items-start` + `break-words`, so a long title gets the full row width
    and ellipsis on overflow instead of being squeezed into a thin column
    that wraps to 12 lines.
  - In inline mode the right-aligned chip cluster (tags + subtasks counter)
    is hidden on the title row and re-rendered in the meta sub-row below
    (subtask counter is rendered without its progress bar to save width).
  - In inline mode the meta sub-row always renders even when no badges are
    present, because the tags/subtask chips guarantee there will be content.
  - Wired `inline` into the sidebar ListRow in `TaskWorkspace.tsx`.

  ## Decisions
  - One renderer with two layouts beats two components: the JSDoc,
    priority badges, hover actions, and badge styling all stay in sync.
  - Subtask counter loses its progress bar in inline mode — the digits alone
    fit in a 16px chip; the bar needs ~32px which doesn't survive a narrow
    column.
  - Kept the meta sub-row in inline mode always-on rather than conditionally
    rendered so a task with tags/subtasks but no badges still shows its chips.

  ## Files
  - src/components/ListRow.tsx (new `inline` prop, two layout branches)
  - src/components/TaskWorkspace.tsx (pass `inline` to sidebar ListRow)
