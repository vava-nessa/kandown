# Restore missing settings controls

## Context

User reported that the Settings page had no language selector, theme
mode switcher, background picker, or font picker — only toggles and
the skin gallery rendered.

## Root cause

In `c6e260b` (v0.30.0 "Fable UI Themes"), the dev replaced the
old `SkinPicker` in `SettingRow` with `ThemeGalleryPicker` and
accidentally dropped the sibling `theme` / `select` / `language` /
`text` / `number` / `permission` branches in the same diff. The
regression was preserved in `7a24047`, `6414c9d`, and the v0.34.1
modular split (`26ab2f5`) that extracted `SettingRow.tsx` to its
own file. Six releases shipped with broken settings rows.

## Fix

Re-added the deleted control branches in
`src/components/settings/SettingRow.tsx`, taking the pre-bug
v0.28.0 implementation as the source of truth. Imports restored
for `ThemeSwitcher` and `LanguageDropdown`.
