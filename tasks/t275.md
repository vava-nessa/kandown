    from drifting.
  - `ownerGlyph` returns 🤖 / 👤 instead of A / H. Both are astral code points, so

# TUI list, sortable headers, priority lens, owner emoji, assignee column

Make the list view's header row do the work it looks like it should do: sort on
click, filter on the priority cell, and say who owns each task without a legend.

## Subtasks

- [x] Sort by clicking any column header, click again to reverse
  report: `sortRows` takes a `ListSortDir`; `sortForColumn` maps each header cell
  to its sort. A new column starts in its natural order, the active one flips.
  Active column shows `↑`/`↓` in cyan.
- [x] Cycle the priority lens from the `Pr` header (and `p`)
  report: `PriorityFilter` = all/P1..P4/untriaged, applied in `buildListRows` and
  `applyBoardFilter` so the board view honours it too. Header cell shows the
  active priority in its colour; footer shows `only P1`.
- [x] Replace the cryptic `O` column with 🤖 / 👤
  report: `ownerGlyph` returns emoji, column renamed `Who` and widened to 4 cells.
  Both glyphs are 2 JS code units and 2 terminal cells, so `pad` keeps the grid.
- [x] Cap titles at 60 characters
  report: `MAX_DESC = 60` in `computeListLayout`. Rows keep the same shape at any
  width; the selected row still wraps and the detail pane holds the full title.
- [x] Add an Assignee column on the far right
  report: 12 cells, drawn after the description, `—` when unassigned. Toggleable
  via `tui.columns.assignee`, dropped early when the terminal is too narrow.
