# Add clickable web URL in TUI header

## Context

The board TUI already showed daemon status and the bottom status bar included the
web daemon URL, but vava wanted the served web page link visible **at the top
right** and clickable from terminals that support hyperlinks.

## Changes

- Added OSC 8 terminal hyperlinks via `terminalHyperlink(label, url)`.
  - Supported terminals render the URL label as clickable.
  - Unsupported terminals still show a normal visible label.
- Main board header now shows the running web URL at the top-right as:

  ```text
  ↗ localhost:<port>
  ```

  The label links to the daemon URL (for example `http://localhost:2050`).
- Detail view header now shows the same clickable web URL on the top-right,
  instead of only `KANDOWN <board title>`.
- Narrow-terminal safety: fixed `truncate(..., 0)` so dynamic header widths never
  produce broken ellipsis output.
- Synced the TUI daemon helper (`src/cli/lib/daemon.ts`) with the robust daemon
  startup logic from the CLI:
  - non-destructive metadata handling on transient fetch failure;
  - TCP port probe for startup detection;
  - 8s startup timeout.

## Verification

- `pnpm typecheck` ✅
- `pnpm build:cli` ✅

## Notes

The clickable behavior depends on terminal OSC 8 support. Modern iTerm2, Kitty,
WezTerm, Ghostty, VS Code terminal, and many recent terminals support it. Others
will simply display the label as plain text.
