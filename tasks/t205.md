# Refactor web column reorder drag indicator

## Context

Vava reported that the newly added column reorder handle works poorly and feels awful. The goal is to make column reordering intuitive by showing a clear insertion line between columns while dragging.

## Subtasks

- [x] Audit current board/column drag implementation
  report: Found the bad UX came from whole-column draggable wrappers, ambiguous index-based drops, and no insertion feedback.
- [x] Refactor column drag state to insertion-slot semantics
  report: Board drag state now tracks a drop slot from 0..columns.length and converts it to the final array index on drop.
- [x] Render a clear vertical insertion indicator between columns
  report: Added a glowing vertical drop guide rendered before columns or after the last column while reordering.
- [x] Restrict column dragging to the reorder handle instead of the whole column
  report: Removed draggable column wrappers; normal columns start reordering from the gripper only, compact empty columns remain directly draggable.
- [x] Verify TypeScript/build
  report: `pnpm typecheck` and `pnpm build` both pass; browser smoke test confirmed the insertion guide appears during drag.
